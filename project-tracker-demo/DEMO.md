# 更新项目进度并核对发布版本

按[启动说明](README.md)打开台账，在另一个终端进入同一项目目录。以下步骤以 P-101「预约时段引擎」为例。重复操作时可改用新的版本号，便于在历史中找到本次记录。

## 更新项目

1. 在首页把「风险」设为「延期」，查看筛选后的项目、里程碑和负责人，再清除筛选。
2. 打开「预约时段引擎」，将完成度设为 75，下一步填写「安排节假日回归」。点击「保存进度」，在「变更记录」核对字段的前后值与时间。

## 提交两次发布回执

先运行一次成功发布。脚本通过本包测试后向本机服务提交回执。

```sh
uv run --offline python scripts/publish.py --project P-101 --version 1.4.0
```

打开「发布历史」，检查正式环境的版本 `1.4.0`、流水线编号和发布时间。再模拟新版本发布失败。

```sh
uv run --offline python scripts/publish.py --project P-101 --version 1.4.1 --result failed
```

脚本以退出码 1 结束。「发布历史」出现版本 `1.4.1` 的失败记录，当前正式版本仍为 `1.4.0`。回到「项目进度」可以看到完成度仍为 75%。

## 与个人飞书多维表格同步

配置步骤见[飞书配置](FEISHU.md)。在表中修改 P-101 的里程碑，在台账「飞书同步」点击「从飞书导入项目」并确认，即可核对更新后的里程碑。随后执行一次发布，在表格同一行核对版本、最近发布结果和时间。仅使用本地模式时，这些记录可直接在项目详情查看。
